# ✅ Working To-Do List

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript.

> 🚧 **Project Status:** Under Development

---

## 📖 About

This project is a beginner-friendly To-Do List application created to practice frontend web development and JavaScript fundamentals.

The application allows users to manage daily tasks through a clean and easy-to-use interface.

---

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and responsive user interface
- Built using HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 📂 Project Structure

```text
working to do list/
│
├── index.html

├── script.js
└── README.md
```

---

## 🎯 Learning Objectives

- Practice semantic HTML
- Improve CSS styling skills
- Learn JavaScript DOM manipulation
- Understand event handling
- Build an interactive web application

---

## 🚀 Getting Started

1. Clone the repository.
2. Open the `working to do list` folder.
3. Open `index.html` in your web browser.
