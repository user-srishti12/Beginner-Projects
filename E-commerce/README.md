# E-Commerce Webpage

A basic E-Commerce webpage created using HTML and CSS. This project is built at a beginner level to practise multi-page website integration, navigation, and clickable category images.

## Features

- Basic e-commerce website layout
- Multiple interconnected pages
- Clickable images for product categories
- Navigation between different pages
- Simple and beginner-friendly design
- Styling using CSS
- Separate HTML pages for different sections

## Pages Included

- `index.html` — Home page
- `category.html` — Category page
- `mycart.html` — My Cart page
- `yourorders.html` — Orders page
- `logout.html` — Logout page
- `faq.html` — Frequently Asked Questions
- `style.css` — Website styling

## Technologies Used

- HTML5
- CSS3

## Multi-Page Integration

The pages are connected to each other using HTML links, allowing users to move between different sections of the website.

The category images are also clickable, allowing users to select a category and navigate to the relevant page.

## Purpose

This project was created as a beginner-level web development project to practise:

- HTML page structure
- CSS styling
- Linking multiple HTML pages
- Using images as clickable links
- Basic website navigation
- Organising project files
