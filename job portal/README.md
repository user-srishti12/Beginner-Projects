# 💼 Job Portal

A simple and responsive Job Portal web application built using HTML and CSS.

> 🚧 **Project Status:** Under Development

---

## 📖 About

This project is a beginner-friendly Job Portal website developed to practice frontend web development using HTML and CSS.

The website provides a clean interface where users can search for jobs and browse available job listings. It is designed to improve my understanding of webpage layouts, navigation, forms, and responsive design.

---

## ✨ Features

- Responsive homepage
- Navigation bar
- Job search section
- Latest job listings
- Job cards with company details
- Apply button for job listings
- Clean and user-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
