# 🏥 MediTrack

MediTrack is a beginner-friendly healthcare web application designed to help users manage their basic medical information in one place.

> 🚧 This project is currently under development.

## 📌 About the Project

The goal of MediTrack is to create a simple and user-friendly platform where users can:

- Store personal profile information
- Track medicines
- View medical records
- Manage healthcare details easily

This project is being developed to improve my frontend development skills using HTML, CSS, and JavaScript.

---

## ✨ Current Features

- Responsive landing page
- User profile section
- Clean and simple UI
- Basic project structure
