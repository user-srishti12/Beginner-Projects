# 🌐 Personal Portfolio Website

A simple and responsive personal portfolio website built using HTML and CSS to showcase my skills, projects, and contact information.

> 🚧 **Project Status:** Under Development

---

## 📖 About

This project is a personal portfolio website created as part of my frontend web development learning journey.

The website is designed to introduce myself, highlight my projects, showcase my skills, and provide an easy way for visitors to get in touch.

---

## ✨ Features

- Responsive homepage
- About Me section
- Projects section
- Contact page
- Simple and clean user interface
- Multi-page website
- Built using HTML and CSS

---

## 🛠️ Technologies Used

- HTML5
- CSS3
