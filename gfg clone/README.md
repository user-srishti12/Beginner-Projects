# 💚 GeeksforGeeks Clone

A beginner-friendly frontend clone of the GeeksforGeeks website built using HTML and CSS.

> 🚧 **Project Status:** Under Development

---

## 📖 About

This project is a basic clone of the GeeksforGeeks homepage created to practice frontend web development using HTML and CSS.

The aim of this project is to improve my understanding of webpage structure, layouts, and styling while recreating the design of a real-world website.

**Note:** This project is created for learning purposes only and is not affiliated with GeeksforGeeks.

---

## ✨ Features

- Homepage layout
- Navigation bar
- Hero section
- Clean and simple user interface
- Built using HTML and CSS

---

## 🛠️ Technologies Used

- HTML5
- CSS3
